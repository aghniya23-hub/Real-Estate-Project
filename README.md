# 🏡 Real Estate Website — Rumah Jelas
Website pencarian properti modern yang dibuat sebagai project tugas kelompok.  
Fokus pada fitur pencarian rumah, filter lengkap, detail properti, wishlist, dan simulasi KPR.

---

## ✨ Fitur Utama
- **Landing Page Modern** (Hero, Feature section)
- **Daftar Properti (Properties Page)**  
  - Mixed Layout (Featured + Grid)
  - Filter lengkap:
    - Search bar
    - Harga (min–max)
    - Jumlah kamar
    - Lokasi
    - Tipe (Rumah / Villa / Cluster)
    - Status verifikasi
    - Sorting (Termurah → Termahal, Terbaru)
- **Detail Properti** (mengambil data berdasarkan ID)
- **Wishlist System** (localStorage)
- **Dark / Light Mode**
- **Simulasi KPR**
  - Perhitungan otomatis
  - Tabel amortisasi singkat
- **Data properti menggunakan JSON**
- **Desain responsif & modern**

## 🚀 Cara Menjalankan Project
1. Clone repo:
   ```bash
   git clone https://github.com/username/real-estate-project.git
````

2. Pastikan struktur folder benar (`css`, `js`, `data`, `img`)
3. Buka file `index.html` di browser
4. Semua halaman saling terhubung otomatis
